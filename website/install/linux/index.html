DropMorph ko Linux pe install karo

Version 1.12.0 · glibc 2.35+ (Ubuntu 22.04 ya naya) · Free
Phone pe ho? DropMorph computer ka app hai (Windows, Mac, Linux). File phone pe bhi download ho jayegi, lekin install aur use computer pe hi hoga. Sabse aasaan: yeh link apne computer pe kholo.

⚡ Sabse aasaan: ek command

Terminal kholo (Ctrl + Alt + T), yeh paste karke Enter dabao:

curl -fsSL https://dropmorph.vercel.app/install.sh | sh

Yeh x64 ya ARM64 ki sahi file khud chunta hai, checksum check karta hai aur DropMorph ko aapke user ke liye install karta hai (sudo nahi). Koi library missing ho to uski install command bata deta hai (Step 2). Dobara chalane se update ho jata hai.

Zaroori libraries (ek baar)

Apne Linux ke hisaab se ek command chalao. (Bhool gaye to bhi install.sh bata dega ki kya missing hai.)

Ubuntu 24.04+ / Mint 22

sudo apt install libicu74 libssl3t64 libfontconfig1 libfreetype6 libx11-6 libice6 libsm6 libxrandr2 libxkbcommon0 libxi6 libxtst6 libxt6 fonts-noto-cjk python3

Ubuntu 22.04 / Mint 21

sudo apt install libicu70 libssl3 libfontconfig1 libfreetype6 libx11-6 libice6 libsm6 libxrandr2 libxkbcommon0 libxi6 libxtst6 libxt6 fonts-noto-cjk python3

Fedora

sudo dnf install libicu fontconfig freetype libX11 libICE libSM libXrandr libxkbcommon libXi libXtst libXt google-noto-sans-cjk-fonts python3

Arch / Manjaro

sudo pacman -S --needed icu fontconfig freetype2 libx11 libice libsm libxrandr libxkbcommon libxi libxtst libxt noto-fonts-cjk python
3

Unzip karke install.sh chalao

cd ~/Downloads
tar -xzf DropMorph-1.12.0-linux-x64.tar.gz      # ARM64 ho to linux-arm64
cd DropMorph-1.12.0-linux-x64
./install.sh

Yeh DropMorph ko aapke user ke liye install karta hai (sudo nahi chahiye), app menu mein DropMorph daalta hai aur dropmorph command add karta hai.

Bina install kiye try karna hai? Unzip kiye folder mein ./DropMorph chala do.
4

Use karo: Ctrl + drag + drop

  1. App menu se DropMorph kholo (system tray mein chalu rehta hai).
  2. Ctrl dabake kisi file ko thoda sa drag karo.
  3. Donut mein jo format chahiye, uspe chhod do. Nayi file original ke bagal mein ban jayegi.

Right-click

Settings → General mein on karo. Nautilus (Files), Nemo, Dolphin aur Thunar mein aata hai.

Drop zone

DropMorph window kholo aur file us box mein daal do.

Terminal

dropmorph convert *.png --to webp

Settings → General → Start DropMorph when I sign in on rakho, taaki login hote hi ready ho.

!

X11 ya Wayland?

Ctrl-drag donut ke liye X11 chahiye. Check karo: echo $XDG_SESSION_TYPE

  • x11 aaye: sab kuch chalega.
  • wayland aaye: drop zone, right-click aur terminal chalenge. Donut ke liye login screen pe gear icon se "GNOME on Xorg" / "Plasma (X11)" chuno.

Problem aa rahi hai?

DropMorph khul hi nahi raha

Terminal se chalao, error dikh jayega: ~/.local/share/dropmorph/application/DropMorph. "ICU" ya "libX11 … cannot open shared object" aaye to Step 2 ki libraries install karo. "GLIBC_2.35 not found" matlab Linux bahut purana hai (Ubuntu 22.04+ chahiye).

Ctrl-drag pe donut nahi aa raha

DropMorph chalu ho (tray icon), aur session X11 ho (upar dekho).

Video ya audio convert nahi ho raha

DropMorph → Settings → Engines se FFmpeg install karo. Purani Office files (DOC, PPT) ke liye sudo apt install libreoffice, phir Check again.

dropmorph: command not found 
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.profile && . ~/.profile
Update kaise karein?

Wahi ek command dobara chala do, ya nayi file unzip karke uska ./install.sh chalao. Settings aur engines bache rahenge.

Uninstall kaise karein? 
~/.local/share/dropmorph/application/uninstall.sh

DropMorph pasand aaya? Free hai aur hamesha rahega. Developer ki help karo: GitHub pe ek ⭐ star do, isse aur log isse dhoondh paate hain.
