Windows 11: "Smart App Control blocked an app"?

Kuch naye Windows 11 PCs mein Smart App Control on hota hai. Yeh unsigned apps ko seedha block kar deta hai, aur isme "Run anyway" ka option hota hi nahi.

  • Check karne ke liye: Start → Settings → Privacy & security → Windows Security → App & browser control → Smart App Control settings.
  • Ise Off karke hi DropMorph install hoga.
  • Dhyan do: Smart App Control ek baar off karne ke baad Windows reset kiye bina wapas on nahi hota. Agar aap yeh nahi chahte, to DropMorph abhi us PC pe nahi chalega.

Use karo: Ctrl + drag + drop

  1. Ctrl key dabake rakho.

  3. Cursor pe formats ka donut khul jayega.
  4. Jo format chahiye (PNG, PDF, MP3…), uspe le jaake chhod do.
  5. Nayi file original file ke bagal mein ban jayegi.
2-key shortcuts: Explorer mein files select karo aur dabao Alt + I (Images), D (Documents), V (Video) ya O (Other). Us type ka donut khul jayega. Keys DropMorph → Settings → Shortcuts mein badal sakte ho.

Problem aa rahi hai?

Ctrl dabake drag karne pe donut nahi khul raha

DropMorph chalu hona chahiye. Windows 11 mein taskbar ke right side pe ^ (teer) dabao, wahan DropMorph ka drop wala icon dikhna chahiye. Na dikhe to Start menu mein "DropMorph" search karke kholo.

Right-click menu mein DropMorph nahi dikh raha WIN 11

Windows 11 ke chhote menu mein na ho to Show more options (ya Shift + right-click) dabao. Top pe chahiye to DropMorph ki Settings → General mein Explorer menu ka option on karo.

"Run anyway" ka button hi nahi hai

Yeh Smart App Control ki wajah se hai. Upar Step 2 ka peela box padho.

Antivirus ne file delete/block kar di

Naye unsigned apps ke saath kabhi-kabhi aisa hota hai. Antivirus ke quarantine mein jaake Restore / Allow karo. Setup seedha GitHub se download karo, kisi aur site se nahi.

Video ya audio convert nahi ho raha

DropMorph mein Settings → Engines pe jaake FFmpeg install karo.

Bina install kiye chalana hai (Portable)

Portable zip download karo. Pehle zip pe right-click → Properties → neeche Unblock tick karke OK dabao, phir unzip karke DropMorph.exe chalao.

Update kaise karein?

Kuch karne ki zaroorat nahi. Naya version aane pe DropMorph khud notice dikhayega. Ek click mein update ho jayega, aur settings aur engines bache rahenge.

Uninstall kaise karein?

Start → Settings → Apps → Installed apps → DropMorph ke aage ⋯ → Uninstall.

Kya meri files kahin upload hoti hain?

Nahi. Sab kuch aapke PC pe hi convert hota hai. DropMorph internet sirf naya version check karne aur aapke chune hue engines download karne ke liye use karta hai.
