DropMorph ko Mac pe install karo

Version 1.12.0 · macOS 14 Sonoma ya naya · Free
Phone pe ho? DropMorph computer ka app hai (Windows, Mac, Linux). File phone pe bhi download ho jayegi, lekin install aur use computer pe hi hoga. Sabse aasaan: yeh link apne computer pe kholo.

⚡ Sabse aasaan: ek command

Terminal kholo (⌘ + Space → "Terminal"), yeh paste karke Return dabao:

curl -fsSL https://dropmorph.vercel.app/install.sh | sh

Yeh aapke Mac (Apple silicon ya Intel) ke liye sahi file khud chunta hai, checksum check karta hai, DropMorph ko ~/Applications mein install karke khol deta hai aur dropmorph command bhi add karta hai. "Open Anyway" ki zaroorat nahi padti. Phir seedha Step 4 pe jao. Dobara chalane se update ho jata hai.

2

Unzip karo aur Applications mein daalo

  1. Downloads folder kholo aur DropMorph-1.12.0-osx-….tar.gz pe double-click karo. Ek folder ban jayega. (Safari aksar yeh khud kar deta hai.)
  2. Folder ke andar DropMorph app hai. Use Finder ke left side mein Applications pe drag karke chhod do.
  3. Applications (ya Launchpad) se DropMorph pe double-click karo.
3

"DropMorph Not Opened" aaye to: Open Anyway

Pehli baar Mac yeh bol sakta hai. Ghabraao mat. Yeh isliye aata hai kyunki DropMorph free app hai aur Apple ki paid notarization nahi hai.

"DropMorph" Not Opened

Apple could not verify "DropMorph" is free of malware that may harm your Mac or compromise your privacy.

DoneMove to Bin
  1. Done dabao (Move to Bin nahi).
  2. Apple menu → System Settings → Privacy & Security kholo.
  3. Neeche scroll karo. "DropMorph" was blocked… ke aage Open Anyway dabao.
  4. Mac ka password daalo, phir dobara Open Anyway. Ab DropMorph khul jayega. Yeh sirf ek baar karna hai.

"DropMorph is damaged and can't be opened"?

App kharab nahi hai, yeh download ka quarantine mark hai. Terminal mein yeh paste karke Return dabao, phir DropMorph normal kholo:

xattr -dr com.apple.quarantine /Applications/DropMorph.app
4

Accessibility on karo (donut ke liye zaroori)

Option-drag se donut kholne ke liye DropMorph ko mouse aur keys dekhni padti hain:

  1. System Settings → Privacy & Security → Accessibility.
  2. List mein DropMorph ka switch on karo. Turant kaam karne lagega.
Accessibility
Allow the applications below to control your computer.
DropMorph
Aur kaam ki settings (DropMorph → Settings → General): Start DropMorph when I sign in on rakho, taaki Mac on hote hi donut ready ho. Convert with DropMorph on karne se Finder ke right-click menu mein bhi aa jayega.

Pehli baar shortcut use karoge to Mac poochega ki DropMorph Finder ko control kare: OK dabao.

5

Use karo: ⌥ Option + drag + drop

  1. ⌥ Option key dabake rakho.
  2. Finder ya desktop se kisi bhi file ko thoda sa drag karo.
  3. Cursor pe formats ka donut khul jayega.
  4. Jo format chahiye (JPG, PDF, MP3…), uspe le jaake chhod do.
  5. Nayi file original file ke bagal mein ban jayegi.

DropMorph upar menu bar mein (top right) rehta hai. Window band karne pe bhi chalu rehta hai.

Right-click

Finder mein file pe right-click → Quick Actions / Services → Convert with DropMorph.

Drop zone

DropMorph window kholo aur file us box mein daal do.

HEIC → JPG

iPhone ki photos (HEIC) ek saath select karke JPG pe drop karo.

2-key shortcuts: Finder mein files select karo aur dabao ⌥ Option + I (Images), D (Documents), V (Video) ya O (Other). Us type ka donut khul jayega. Keys DropMorph → Settings → Shortcuts mein badal sakte ho.
+

Video aur audio ke liye FFmpeg (optional)

Images, PDF, Word, Excel, PowerPoint, ZIP bina kuch install kiye chalte hain. Video/audio (MP4, MOV, MP3, WAV) ke liye Mac pe FFmpeg Homebrew se aata hai. Terminal mein:

# Homebrew nahi hai to pehle yeh (ek baar):
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
# phir FFmpeg (aur EPS/PS ke liye Ghostscript):
brew install ffmpeg ghostscript

Phir DropMorph → Settings → Engines → Check again. LibreOffice (DOC, PPT, Pages, Keynote), Pandoc aur calibre wahi Install button se aa jaate hain.

Problem aa rahi hai?

Option dabake drag karne pe donut nahi khul raha

1) DropMorph chalu hona chahiye (menu bar mein drop wala icon). 2) System Settings → Privacy & Security → Accessibility mein DropMorph on ho. 3) Update ke baad on dikh raha ho phir bhi kaam na kare: DropMorph ko list mein select karke − se hatao, phir + se Applications/DropMorph dobara add karke on karo.

"Open Anyway" button nahi dikh raha

Pehle DropMorph ek baar kholne ki koshish karo (tab hi button aata hai), phir Privacy & Security mein sabse neeche dekho. Ya upar wala xattr command chala do, ya ek command se install karo.

Right-click mein "Convert with DropMorph" nahi hai

DropMorph → Settings → General mein on karo. Finder menu mein yeh neeche Quick Actions ya Services ke andar hota hai. Phir bhi na dikhe to ek baar log out / log in karo.

Video ya audio convert nahi ho raha

FFmpeg chahiye: upar Video/Audio wala step dekho (brew install ffmpeg).

dropmorph: command not found 
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zprofile && source ~/.zprofile
Update kaise karein?

Naya version aane pe DropMorph notice dikhayega. Wahi ek command dobara chala do, ya nayi file download karke purane DropMorph ki jagah Applications mein daal do (Replace). Settings aur engines bache rahenge.

Uninstall kaise karein?

DropMorph ko menu bar se Quit karo, phir Applications se Bin mein daal do. Pura saaf karna ho to ~/Library/Application Support/DropMorph folder bhi delete kar do.

Kya meri files kahin upload hoti hain?

Nahi. Sab kuch aapke Mac pe hi convert hota hai. DropMorph internet sirf naya version check karne aur aapke chune hue engines download karne ke liye use karta hai.

DropMorph pasand aaya? Free hai aur hamesha rahega. Developer ki help karo: GitHub pe ek ⭐ star do, isse aur log isse dhoondh paate hain.
