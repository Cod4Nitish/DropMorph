Formats

If you can drag it, you can morph it.

A quick look at what goes in and what comes out.

Images

JPG, PNG, WEBP, AVIF, HEIC, TIFF, GIF, ICO, PSD, RAW, JPEG XL → any of these, PDF or SVG

PDF

→ DOCX, TXT, PNG, JPG, PPTX, CBZ · merge, split, page ranges, compress

Documents

DOCX, DOC, ODT, RTF, EML, MSG, Pages → PDF, DOCX, EPUB, TXT, HTML

Spreadsheets

XLSX, XLS, ODS, CSV, Numbers → PDF, XLSX, CSV, JSON, HTML

Presentations

PPTX, PPT, ODP, Keynote → PDF, PNG, JPG, DOCX

Video

MP4, MOV, MKV, WEBM, AVI → MP4 (H.264/HEVC/AV1), WEBM, GIF, MP3, 720p, subtitles

Audio

MP3, WAV, FLAC, M4A, OGG, OPUS, AIFF → MP3, M4A, WAV, FLAC, OGG, OPUS

E-books

EPUB, MOBI, AZW3, FB2, CBZ, CBR → PDF, EPUB, KEPUB, DOCX, TXT

Archives

ZIP, 7Z, RAR, TAR, GZ, ISO, DMG → extract, ZIP, 7Z, TAR

Fonts and data

TTF, OTF, WOFF2 ↔ each other · JSON, YAML, TOML, XML ↔ each other, CSV, XLSX

CAD and 3D

DWG, DXF → PDF, SVG, PNG · GLB, glTF, STL, OBJ, 3MF ↔ each other

Maps

Shapefile, GeoJSON, KML, KMZ, GPX ↔ each other, CSV, XLSX, JSON

Most formats work out of the box. Some (video and audio, legacy Office, e-books) use an optional engine that DropMorph downloads only when you need it.

Command line

Prefer typing? There's a command for that.

The dropmorph command uses the same engines and presets as the app. Great for scripts and automation.

# one file
$ dropmorph convert photo.heic --to jpg

# a whole folder, smaller files
$ dropmorph convert *.png --to webp --quality 80 -o converted

# convert everything that lands in a folder
$ dropmorph watch D:\Inbox --to pdf --move-originals

FAQ

Questions

Are my files uploaded anywhere?

No. Everything is converted on your own computer. DropMorph only goes online to check GitHub for a newer version, and to download an optional engine you choose to install.

Is it really free?

Yes. DropMorph is free and open source under the MIT license. No account, no watermark, no limits.

Do I need Microsoft Office or LibreOffice?

No. Word, Excel, PowerPoint, PDF and most other formats work out of the box. Only a few legacy formats use an optional engine.

Why does Windows show a warning when I install?

Releases aren't code-signed yet, so SmartScreen doesn't recognize them. Click "More info" → "Run anyway". The installer is built by GitHub Actions straight from the public source code.
