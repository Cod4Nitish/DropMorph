Combine invoices, certificates or scanned pages into a single PDF. Select the files, drag and drop them on Merge PDF. That's it.

How to

PDF to one PDF in three steps

1

Hold Ctrl and drag

Select your PDF file (or many), hold Ctrl (Option on macOS) and start dragging.

2

Drop on Merge PDF

A donut of formats opens at your cursor. Drop the file on Merge PDF.

3

Done

The new file is saved right next to the original. Prefer menus? Right-click the file → DropMorph.

Works out of the box. No extra software or engine download needed.

FAQ

PDF to one PDF: questions

In which order are the files merged?

In the order of the selection you drag.

Can I split a PDF too?

Yes. Drop it on Split PDF to get one file per page.

Are my files uploaded?

No. DropMorph converts everything on your own computer and works offline.

Is DropMorph free?

Yes. Free and open source, with no sign-up, watermark or limits.
