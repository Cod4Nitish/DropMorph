Optional engines

Downloaded only when needed

Each engine is a free program pinned to an official download and checked (SHA-256) before use. Manage them any time in Settings → Engines.

FFmpeg~100 MBAll video and audio: MP4, MKV, MOV, WEBM, MP3, WAV, FLAC…, GIF from video, subtitles

Pandoc~42 MBMarkdown and markup: LaTeX, reStructuredText, AsciiDoc, Org, Jupyter…
Ghostscript~20 MBEPS and PostScript, PostScript-based AI files
