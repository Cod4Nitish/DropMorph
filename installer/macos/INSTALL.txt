This package requires macOS 14 or later and contains a separate build for
Apple Silicon or Intel Macs. The .NET runtime is included.
Which package: Apple menu > About This Mac. "Chip: Apple M1" (M2, M3, M4, ...) needs
osx-arm64; "Processor: ... Intel" needs osx-x64.

Install with Terminal (recommended): open Terminal in this folder and run ./install.sh
(or drag install.sh into a Terminal window and press Return). It copies DropMorph.app to
~/Applications, adds the dropmorph command (~/.local/bin/dropmorph), removes the
download quarantine so macOS doesn't block the first start, and opens DropMorph.
To update, run the install.sh of the newer package: settings and engines are kept.

Install by dragging (.dmg): open the disk image and drag DropMorph.app onto the
Applications folder next to it. Keep its location stable so Accessibility and Finder
Automation permissions continue to identify it.

Packages are ad-hoc signed and are not notarized. When macOS blocks the first start
of a dragged-in copy ("DropMorph" Not Opened / cannot be verified): click Done, open
System Settings > Privacy & Security, scroll down and click Open Anyway next to the
DropMorph message, then confirm with your password. If macOS says the app "is damaged",
run once in Terminal:
  xattr -dr com.apple.quarantine /Applications/DropMorph.app
Only open a build whose source and checksum you trust.

After an update, if Option-drag stops working although Accessibility shows DropMorph
switched on: select DropMorph in that list, remove it with "-" and add it again with "+".
(Each build has a new signature, which macOS treats as a new app.)

Allow DropMorph in System Settings > Privacy & Security > Accessibility for global
gestures. Allow Finder under Automation when using a selection shortcut.
"Convert with DropMorph" in Finder's right-click menu is switched on in DropMorph
settings. Services can also be managed under System Settings > Keyboard >
Keyboard Shortcuts > Services.

Run ./uninstall.sh to remove the ~/Applications installation, integration and
DropMorph-downloaded engines. Your settings and conversion results are kept.
If integration cleanup fails, the installation is kept so you can fix the error
and run the uninstaller again. A manually placed app in
/Applications can be removed after running its DropMorph executable with
--uninstall-cleanup.

rhwp and 7-Zip are bundled. Pandoc, LibreOffice and calibre can be installed in DropMorph
settings > Engines. FFmpeg (video, audio) and Ghostscript (EPS, PS) come from Homebrew
(https://brew.sh): brew install ffmpeg ghostscript, then click "Check again".
